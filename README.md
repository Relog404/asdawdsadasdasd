# Поле тишины

Небольшая 3D-песочница на Godot. В ней только большое открытое поле и персонаж из приложенных Blockbench-файлов. Сцена использует `dfgdrgrd.bbmodel` для рига и ключей анимации, а геометрию и UV читает из `dfgdrgrd.obj`; атлас текстуры — `texture.png`.

## Запуск

Откройте `project.godot` в Godot 4.7.2 и запустите проект (F6/F5). Проект намеренно использует базовые API Godot 4.x и совместимый рендерер GL Compatibility.

## Управление

- **W A S D** — ходить; **Shift** — бежать.
- **C** или **Ctrl** — присесть и проиграть анимацию `prised`.
- **Z** — проиграть анимацию `ziga` из модели.
- **ЛКМ + мышь** — захватить указатель и вращать камеру; **Esc** — отпустить.
- **Колесо мыши** — приблизить / отдалить камеру.

Анимации `walking`, `prised` и `ziga` считываются непосредственно из `.bbmodel`. `Z` проигрывает зига до конечной позы и удерживает её; движение или повторное нажатие возвращает обычную позу. Для ходьбы дополнительно добавлен чередующийся шаг ног: в исходном файле ходьба анимирует только верхнюю часть тела.
